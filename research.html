OctopusONN

A federated neural network architecture for insider threat detection built on continuous-time liquid neural networks. OctopusONN is designed to detect behavioral drift across distributed environments without centralizing sensitive data, preserving privacy while maintaining detection fidelity.

Technical Focus Areas

  • Continuous-time liquid neural networks (CfC/NCP architecture)
  • Federated learning across distributed nodes
  • Behavioral drift detection and anomaly scoring
  • Privacy-preserving inference

OctopusONN addresses the hard case in the Opaque Clarity Security Framework: detecting insider behavioral drift before a technical event occurs.

Project DOUGLAS

A multi-objective pathfinding system with CVaR risk scoring, extended to model cyber lateral movement. Project DOUGLAS maps the decision space an adversary navigates inside a compromised environment, giving defenders a probabilistic view of likely escalation paths before they occur.

Technical Focus Areas

  • Multi-objective pathfinding under uncertainty
  • CVaR risk scoring for adversarial modeling
  • Cyber lateral movement variant
  • Defender-side probability mapping

Project DOUGLAS operationalizes the opacity side of the Opaque Clarity Security Framework: understanding what an adversary sees so defenders can eliminate that view.

OC|Intel

A live threat intelligence platform built under the Opaque Clarity Security Framework. OC|Intel aggregates feeds from seven curated sources, enriches CVEs via the NVD API, flags articles against the CISA Known Exploited Vulnerabilities catalog, and surfaces insider threat signals alongside technical telemetry. KEV-flagged and critical severity items are prioritized automatically.

Technical Focus Areas

  • Behavioral indicator integration and insider threat tagging
  • CVE enrichment via NVD API with severity scoring
  • CISA KEV catalog flagging and prioritization
  • Multi-source threat intelligence aggregation

OC|Intel is the defender-visibility component of the Opaque Clarity Security Framework: unified signal across human and network indicators in a single surface.
